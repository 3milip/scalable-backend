Cześć — to sprawdzarka kodu

Wybierasz zadanie, wklejasz program i wysyłasz. System wrzuca go do kolejki, a potem (gdy będzie worker) porówna wynik z testami i powie, czy jest dobrze.

zadania lista zgłoszenia wyniki obciążenie kolejka

Jak tego użyć

  1. Odpal frontend: python -m http.server 3000 (katalog frontend/)
  2. Odpal backend na :8000 i sprawdzarkę na :8002
  3. Wejdź w Zadania
  4. Kliknij tytuł, wklej kod, wyślij
  5. Zobacz zgłoszenie — na razie zostanie queued
